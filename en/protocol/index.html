Suggested first path

If this is your first time here, the least confusing order is: read the book first, then use the wiki to build a sense of direction, and finally return to the repository to see how the protocol grows in both document and publication layers.

  • Read TRP AI First as the first public entry.
  • Open the public wiki to browse terms, topic pages, and cross-links without starting from raw repository structure.
  • Open the GitHub repository to see the protocol body, specs, and history.
  • Return later for product and playground layers as they are rebuilt.
