隱私權政策

最後更新：2026-09-30

本頁說明四分之三國際有限公司如何處理公開網站、早期產品（包含言途 Dialogue Trainer 與 Fathom），我們自有的社群發布工具，以及我們經營的 LINE 官方帳號相關的資料。

公開網站

本網站由 GitHub Pages 託管、經 Cloudflare 傳送，並從 Google Fonts 載入字型。你瀏覽網頁時，這些服務會收到瀏覽器為了載入頁面而送出的技術資訊，例如 IP 位址、瀏覽器類型與請求時間。你寫信到 info@three-quarters.net 詢問服務時，信件內容用於回覆你與後續的報價、合作。

我們可能蒐集的資料

言途 Dialogue Trainer 與 Fathom 目前皆為早期產品。依你的使用方式，應用程式可能會處理：

  • Google 登入的個人資料，例如電子郵件、顯示名稱與頭像。
  • 訪客或帳號連結後的遊戲進度、重播紀錄、設定與雲端存檔資料。
  • 你在訓練場景中輸入的對話回應，以及 AI 生成的評估結果。
  • 你在 Fathom 中輸入的生日、稱呼、探索主題、Kin 筆記、AI mirror 對話與收攝草稿。
  • 你在應用程式中提交的回饋與問題回報。
  • 為了讓服務運作所需的基本技術資訊，例如瀏覽器請求、時間戳與錯誤紀錄。

我們如何使用資料

我們僅將資料用於產品運作、學習延續、安全維護與改進。

  • 讓你能登入、延續旅程，並在啟用雲端存檔時同步練習進度。
  • 評估訓練回應、產生 NPC 反應，提供教練回饋，或在 Fathom 中生成鏡子回應與筆記收攝。
  • 診斷錯誤、失敗的 AI 生成、登入問題或存檔問題。
  • 改進應用程式的訓練設計與場景品質。

AI 處理

應用程式中提交的對話文字，可能會被傳送至 AI 服務供應商，以便產品生成 NPC 反應、評分、回饋、復盤摘要、AI mirror 回應或筆記收攝。如果你不希望相關文字被用於這些功能處理，請勿輸入敏感個資。

社群帳號的發布工具

我們自行開發並自行使用一套社群發布工具，透過 Meta 的 Graph API 發布內容到四分之三國際自有的 Facebook 粉絲專頁，以及我們受託營運的 Instagram 商業帳號。 這套 production 工具不對一般使用者開放—— 它只由公司內部人員操作，處理的是我們自己（或委託我們的客戶）的帳號。 FoZone Manager 另提供一個限授權管理員使用的 OAuth 接入頁，用於 Meta 應用程式檢閱、唯讀權限診斷，以及未來由客戶親自連接其商家資產。

  • 它會處理：帳號的公開識別資訊（粉絲專頁名稱、帳號代稱、編號）、我們準備要發布的文字與圖片、發布結果的識別碼與連結。
  • 它會讀取聚合的成效數字，例如瀏覽次數、觸及人數、按讚與留言的數量。
  • 當這些帳號收到留言或私訊時，它可能會讀取留言與訊息的內容、發送者的顯示名稱與帳號識別碼，用於回覆、客服與社群經營。若由 AI 協助草擬或發送回覆，相關文字可能會被傳送至 AI 服務供應商處理（見上節〈AI 處理〉）。
  • 這些內容只用於該帳號的經營與回應。我們不會用它建立受眾名單、不做跨帳號的個人剖繪、不販售、不與廣告以外的第三方分享。
  • 我們不會把留言內容或發送者身分寫進任何公開紀錄（包含公開的程式碼倉儲與對外文件）。
  • 它不會主動蒐集未與我們互動之一般 Facebook 或 Instagram 使用者的個人資料。

存取這些帳號所需的憑證，以加密形式保存在公司內部，只在發布或讀取成效的當下使用，不寫入文件、不進入對話紀錄、不與任何第三方分享。我們不販售、不交換這些資料，也不將它們用於廣告投放以外的第三方用途。受託營運的客戶帳號，其資料與存取權限隨委託關係結束而歸還或撤銷。

OAuth 接入頁會在使用者明確授權後，於當次瀏覽器分頁中處理管理員顯示名稱、可管理的粉絲專頁、近期貼文，以及公開留言的內容、時間、留言編號、發送者顯示名稱與帳號識別碼。 OAuth 權杖與 API 回應不會由該頁傳送至或保存於本網站的伺服器；權杖只存在當頁記憶體，並在重新整理、關閉或清除連線時消失。該頁不會發文、回覆、編輯、刪除、執行 moderation 或建立廣告受眾。

LINE 官方帳號

我們透過 LINE 的 Messaging API 經營自有與受託的 LINE 官方帳號，目前為「四分之三 Three-Quarters」（公司自有）與「宇宙媽媽賞」（受託經營）。這些帳號在 LINE 開發者平台上都登記在「四分之三國際有限公司」名下。

  • 當你把這些帳號加為好友，LINE 會提供我們一組代表你的使用者識別碼。這組識別碼由 LINE 按「服務提供者」（provider）核發，而我們經營的帳號都登記在同一個服務提供者之下：同一個人加入其中不同帳號時，識別碼相同，所以我們可能認得出是同一位好友。我們不會用姓名、頭像或行為去推測你是誰。
  • 我們會讀取帳號的聚合統計，例如好友人數、訊息的送達與開啟數。
  • 我們可能透過 API 對好友發送訊息，例如群發訊息或圖文選單。
  • 「宇宙媽媽賞」的一對一聊天，仍由帳號經營者本人在 LINE 官方帳號的管理工具中處理，我們的系統不接收它的一對一訊息內容。若這一點改變，會先更新本政策。
  • 我們目前不把同一位好友在不同帳號的紀錄合併使用；若要這樣做，也會先更新本政策。
  • 好友資料只用於該帳號的經營與回應，不販售、不交換，也不寫進任何公開紀錄。

「四分之三 Three-Quarters」的一對一聊天：由 AI 數位人佛佐回覆，對話會保存

  • 誰在蒐集：四分之三國際有限公司。
  • 為什麼：回覆你的訊息、延續你與佛佐之間的往來，以及經營與你的聯繫關係。
  • 蒐集什麼：你的 LINE 使用者識別碼、當時的顯示名稱（不含頭像）、你傳來的訊息與圖片、影片、語音、檔案，以及我們的系統送給你的回覆。保存的是本系統實際收到與送出的訊息；負責人 Darren 在 LINE 官方帳號管理工具裡親自打的回覆，目前不在系統保存範圍內。
  • 怎麼處理：佛佐是 AI，由 AI 模型扮演，每則回覆上方會標出當下的模型（目前是 Google Cloud Vertex AI 上的 Gemini）。產生回覆時，系統只會把你與佛佐之間的往來交給模型，不會有其他人的對話。第一次對話時，佛佐會先告訴你她是 AI、對話會保存。遇到報價、合約、付款、時程、刪除或查詢資料、需要真人或你提到危險的情況，她會交給負責人 Darren；系統會用 Telegram 通知 Darren，通知只包含你的顯示名稱、一個內部代號與交接原因，不含你的訊息內容。當你明確問到三界協議、協議裡的詞條或文件代號（例如 LEX·007）時，系統可能先向我們營運的三界協議公開文庫查詢相關段落，再把查回的有限引用資料連同對話交給模型組成回覆。送去查詢的只有從你最新一則文字訊息整理出的搜尋詞（最多 240 字），不含你的 LINE 使用者識別碼、顯示名稱，也不含你較早傳來的訊息或完整對話紀錄。這個文庫是「公開」的，意思是文庫內容任何人都能查閱；你送去的查詢本身不會公開。
  • 交給誰、在哪裡：公司內部只有負責人 Darren 可以存取。受我們委託處理的服務供應商有：Google（以 Vertex AI 產生回覆；以公司的 Google 雲端硬碟保存備份，只限公司內部存取）、Cloudflare（以加密通道把 LINE 送來的訊息轉進我們的主機）與 Telegram（給負責人的通知）；LINE 本身也保存你們的聊天紀錄。三界協議公開文庫的查詢服務由我們營運，運行在 Google Cloud，目前位於歐洲比利時的機房（europe-west1）；這個服務和它的入口不記錄查詢內容，只留下請求時間、路徑與處理結果等技術紀錄。這些服務的伺服器可能位在台灣以外的地區。我們不拿這些對話訓練或微調模型，也不提供給其他第三方。
  • 保存多久：保存到你要求刪除，或這個帳號停止經營為止。
  • 你的權利：依《個人資料保護法》第 3 條，你可以請求查詢或閱覽、製給複製本、補充或更正、停止蒐集處理利用，以及刪除。寫信到 info@three-quarters.net，或直接跟佛佐說，她會轉交 Darren 處理。要求停止蒐集後，你之後傳來的訊息系統不再記錄、也不再回覆，直到你請我們恢復；已保存的紀錄，你可以一併要求刪除。刪除時，我們會刪掉系統資料庫、保存的圖片檔案與雲端備份裡與你有關的紀錄，並撤回 48 小時內給 Darren 的通知；LINE 那一端的聊天紀錄由 LINE 保管，你可以在 LINE 刪除聊天室。
  • 如果你不提供：加不加好友、傳不傳訊息都由你決定。不傳訊息，我們就無法在 LINE 上回覆你；你也可以改寫信聯絡。

存取這些帳號所需的憑證，與上節相同，以加密形式保存在公司內部，只在使用當下解開。受託經營的帳號在委託關係結束時，我們停止以該帳號發送訊息或讀取資料。

儲存與刪除

部分練習資料可能會儲存在你的瀏覽器本地端。如果你登入並使用雲端存檔，資料也可能存放在應用程式所使用的雲端基礎設施中。隨著功能逐步上線，應用程式可能會提供清除本地記憶、刪除雲端存檔，或匯出帳號資料的控制選項。
