隱私權政策

最後更新：2026-09-26

本頁說明四分之三國際有限公司如何處理公開網站、早期產品（包含言途 Dialogue Trainer 與 Fathom），以及我們自有的社群發布工具相關的資料。

我們可能蒐集的資料

言途 Dialogue Trainer 與 Fathom 目前皆為早期產品。依你的使用方式，應用程式可能會處理：

  • Google 登入的個人資料，例如電子郵件、顯示名稱與頭像。
  • 訪客或帳號連結後的遊戲進度、重播紀錄、設定與雲端存檔資料。
  • 你在訓練場景中輸入的對話回應，以及 AI 生成的評估結果。
  • 你在 Fathom 中輸入的生日、稱呼、探索主題、Kin 筆記、AI mirror 對話與收攝草稿。
  • 你在應用程式中提交的回饋與問題回報。
  • 為了讓服務運作所需的基本技術資訊，例如瀏覽器請求、時間戳與錯誤紀錄。

我們如何使用資料

我們僅將資料用於產品運作、學習延續、安全維護與改進。

  • 讓你能登入、延續旅程，並在啟用雲端存檔時同步練習進度。
  • 評估訓練回應、產生 NPC 反應，提供教練回饋，或在 Fathom 中生成鏡子回應與筆記收攝。
  • 診斷錯誤、失敗的 AI 生成、登入問題或存檔問題。
  • 改進應用程式的訓練設計與場景品質。

AI 處理

應用程式中提交的對話文字，可能會被傳送至 AI 服務供應商， 以便產品生成 NPC 反應、評分、回饋、復盤摘要、AI mirror 回應或筆記收攝。 如果你不希望相關文字被用於這些功能處理，請勿輸入敏感個資。

社群帳號的發布工具

我們自行開發並自行使用一套社群發布工具，透過 Meta 的 Graph API 發布內容到四分之三國際自有的 Facebook 粉絲專頁，以及我們受託營運的 Instagram 商業帳號。 這套 production 工具不對一般使用者開放—— 它只由公司內部人員操作，處理的是我們自己（或委託我們的客戶）的帳號。 FoZone Manager 另提供一個限授權管理員使用的 OAuth 接入頁，用於 Meta 應用程式檢閱、 唯讀權限診斷，以及未來由客戶親自連接其商家資產。

  • 它會處理：帳號的公開識別資訊（粉絲專頁名稱、帳號代稱、編號）、我們準備要發布的文字與圖片、發布結果的識別碼與連結。
  • 它會讀取聚合的成效數字，例如瀏覽次數、觸及人數、按讚與留言的數量。
  • 當這些帳號收到留言或私訊時，它可能會讀取留言與訊息的內容、發送者的顯示名稱與帳號識別碼，用於回覆、客服與社群經營。若由 AI 協助草擬或發送回覆，相關文字可能會被傳送至 AI 服務供應商處理（見上節〈AI 處理〉）。
  • 這些內容只用於該帳號的經營與回應。我們不會用它建立受眾名單、不做跨帳號的個人剖繪、不販售、不與廣告以外的第三方分享。
  • 我們不會把留言內容或發送者身分寫進任何公開紀錄（包含公開的程式碼倉儲與對外文件）。
  • 它不會主動蒐集未與我們互動之一般 Facebook 或 Instagram 使用者的個人資料。

存取這些帳號所需的憑證，以加密形式保存在公司內部，只在發布或讀取成效的當下使用， 不寫入文件、不進入對話紀錄、不與任何第三方分享。 我們不販售、不交換這些資料，也不將它們用於廣告投放以外的第三方用途。 受託營運的客戶帳號，其資料與存取權限隨委託關係結束而歸還或撤銷。

OAuth 接入頁會在使用者明確授權後，於當次瀏覽器分頁中處理管理員顯示名稱、可管理的粉絲專頁、 近期貼文，以及公開留言的內容、時間、留言編號、發送者顯示名稱與帳號識別碼。 OAuth 權杖與 API 回應不會由該頁傳送至或保存於本網站的伺服器；權杖只存在當頁記憶體， 並在重新整理、關閉或清除連線時消失。該頁不會發文、回覆、編輯、刪除、執行 moderation 或建立廣告受眾。

儲存與刪除

部分練習資料可能會儲存在你的瀏覽器本地端。 如果你登入並使用雲端存檔，資料也可能存放在應用程式所使用的雲端基礎設施中。 隨著功能逐步上線，應用程式可能會提供清除本地記憶、刪除雲端存檔， 或匯出帳號資料的控制選項。
