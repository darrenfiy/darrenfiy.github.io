建議的第一條路徑

如果你第一次進來，最不會迷路的順序是先看書，再用知識庫建立方向感，最後回 repo 看協議如何在文件層與出版層同時生長。

  • 先讀《TRP AI First》作為第一個公共入口。
  • 打開公共知識庫瀏覽詞條、主題頁與交叉連結，不必從原始儲存庫結構開始。
  • 打開 GitHub 儲存庫，查看協議本體、規格與歷史。
  • 之後在產品層與 playground 層重建時，再回來看新的版本。
